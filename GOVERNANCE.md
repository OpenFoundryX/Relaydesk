# Governance

Relaydesk currently uses a maintainer-led governance model suitable for an
early-stage project.

## Roles

- **Contributors** participate through issues, discussions, documentation, and
  pull requests.
- **Maintainers** review contributions, manage releases and repository access,
  moderate community spaces, and make final project decisions.

## Decision making

Routine decisions happen through issue and pull request review. Significant
changes should begin with a public issue describing the problem, alternatives,
and tradeoffs. Maintainers seek community input and rough consensus, while
retaining final responsibility for project direction, security, licensing, and
release quality.

## Becoming a maintainer

Maintainers may invite contributors who have demonstrated sustained, high-quality
participation, sound judgment, respectful collaboration, and familiarity with
the project. Access is granted gradually and may be removed for inactivity,
security concerns, or violations of the Code of Conduct.

This document may evolve as the contributor community grows. Material governance
changes will be discussed publicly before adoption.
