# Security Policy

## Supported versions

Relaydesk is in early development and has not published a stable release. Only
the latest code on the default branch receives security fixes.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues, pull
requests, or discussions.

Use GitHub's **Report a vulnerability** option on the repository's Security
page to send the maintainers a private report. If private vulnerability
reporting is unavailable, open a public issue containing no vulnerability
details and ask a maintainer for a private contact method.

Include, when possible:

- A description of the vulnerability and its impact
- Reproduction steps or a minimal proof of concept
- Affected versions, configurations, or endpoints
- Any suggested mitigation

Maintainers will acknowledge a report as soon as reasonably possible, validate
the issue, coordinate a fix, and credit the reporter if requested. Please allow
time for a fix before public disclosure.

This process is for security vulnerabilities. Use the regular issue templates
for bugs and feature requests.
