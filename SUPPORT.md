# Support

Relaydesk is an early-stage community project.

- For reproducible bugs, open a bug report using the issue template.
- For feature proposals, open a feature request.
- For setup questions, open a question issue and include relevant environment
  details and sanitized logs.
- For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of posting
  publicly.

Community support is provided on a best-effort basis. There are currently no
guaranteed response times or service-level agreements.
